NEEDS TO BE REWRITTEN FOR NEW FINAL STATE.

A search is performed for the decay $B^+ \rightarrow p \Lambda^0$.
This decay violates baryon number (B) by 2 units, given that there are 
no baryons in the initial state and 2 baryons in the final state
(charge conjugation is implied throughout this document).
The \Lam candidate will be reconstructed in
the $p\pi^-$ final state and so the charge conjugation of the proton will tag the charge conjugation
of the \Lam. This decay would be a signature of physics beyond the Standard Model.
There is no tree-level diagram that would mediate this process and in the high-energy
regime would be interpreted as a cascading decay of new high-mass scalar particles.
In the low-energy regime, an effective field-theory approach would be employed.
The flavor/generation dependence of this type of interaction can be constrained
by a comprehensive search of multiple processes.\\

This analysis will be the first search for these processes.
